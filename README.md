# 任务栏指数行情

Rust原生程序，支持Windows 11 x64和Windows Server 2022 x64桌面体验版，仅处理主屏水平任务栏。

## 功能

A股包含上证、创业板、深成指、科创50、北证50；美股包含纳斯达克综合指数、标普500、道琼斯工业平均指数。

行情以子窗口嵌入任务栏空白区域，使用白色圆角背景、15逻辑像素Arial字体，红涨绿跌，平盘与状态文字为深灰色。指数之间间距为6逻辑像素，不显示行情时间。

每2秒请求一次行情，慢请求结束后再发起下一次。空间足够时显示全部指数，否则至少显示一项，每15秒向后轮播一项。空间不足一项或无法可靠识别布局时隐藏，不移动、缩小或遮挡其他应用图标。

## 使用

直接运行`sse-taskbar.exe`，滚轮前后切换行情；右键通知区域的托盘图标，菜单仅包含“退出”。图标可能位于折叠区，悬停提示固定为“指数行情”。休市或行情隐藏时，仍可通过托盘退出。

程序使用双缓冲绘制，相同内容不重复刷新。焦点、选中状态及输入语言设置通知不会直接触发隐藏；若任务栏控件实际增删、重排或移动，仍重新检测布局。Explorer重启后自动尝试恢复托盘和行情。更新程序前，先退出旧实例。

## 登录自启动

正常运行时检查当前用户的登录自启动项，缺失时创建，路径变化时更新。将EXE复制或移动到其他目录后，运行新副本一次即可更新；仅复制文件不会更新。

退出程序不会删除自启动项。`--no-autostart`只跳过本次检查；`--diagnose`不修改自启动。程序不会重新启用被Windows设置或任务管理器禁用的启动项。自启动设置失败会提示，但不阻止行情运行。

## 交易时段与数据

A股交易日北京时间09:30开始显示，午休和收盘后保留当天行情，直到美股开盘；美股休市时保留至北京时间午夜。美股仅在美东常规交易时段显示，处理夏令时、提前收市和跨北京时间午夜。

内置A股2026年、美股2026—2028年交易日历。未知年份按休市处理，2027年使用A股功能前需更新程序。日历和图标编译进EXE，运行时不需要外部文件。

行情来自腾讯公开HTTPS接口，可能延迟。未取得当天数据时显示等待提示；请求失败时保留已取得的当天行情并标为“旧”。

## 构建

在项目根目录使用PowerShell执行：

```powershell
./build.ps1
```

脚本运行`cargo test --locked`和`cargo build --release --locked`，仅交付`dist/sse-taskbar.exe`，不复制README，不生成ZIP。

存在`.tools`便携工具链时优先使用，不修改系统PATH。使用系统工具链时，GNU需要`windres`，MSVC需要Windows SDK的`rc.exe`及开发环境。

## 排障与验证

```powershell
.\sse-taskbar.exe --diagnose taskbar-diagnostics.txt
```

诊断包含版本、市场、任务栏宿主和布局错误，不收集应用窗口标题或凭据。无行情时先检查交易时段、日历年份和任务栏剩余空间。

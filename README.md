# Windows 指数任务栏窄条（Rust）

面向 Windows 11 和 Windows Server 2022（Desktop Experience）的原生 Rust 程序。行情窗口以 `WS_CHILD` 嵌入主屏任务栏内部，不再使用置顶覆盖窗口。程序读取现有控件边界，只使用空白位置，不移动或缩小现有应用图标、文字和通知区。

A股显示上证、创业板、深成指、科创50、北证50；美股显示纳斯达克综合指数、标普500、道琼斯工业平均指数。红涨绿跌，每10秒请求一次行情。空白区域足够时同时横向显示全部指数；不足时显示能放下的数量，每5秒向后轮播一项。

## 使用

在自己的桌面会话中运行 `sse-taskbar.exe`，无需安装或管理员权限。程序自动选择任务栏空白区域，不需要拖动。滚轮前后切换行情；右键行情条或托盘图标，可刷新、翻页、查看规则或退出。休市隐藏行情，但进程和托盘保留，自动等待下次开市。不自动设置开机启动。

任务栏被其他按钮占满、没有足够空间放下一项，或无法可靠识别布局时，暂停显示；原因可在托盘菜单中查看。不会为了强行显示而遮挡现有按钮。关闭程序后只销毁自己的子窗口，不需要恢复系统图标位置。

- A股交易日北京时间09:30开始显示；午休保留；15:00后保留当天收盘行情。
- 美股交易日美东09:30开盘时切换美股；16:00收盘后隐藏，提前收市日13:00隐藏。根据 `America/New_York` 自动处理夏令时和跨北京时间午夜。
- 美股休市而A股当天交易时，A股收盘行情保留到北京时间午夜。A股休市、美股开市时，仍正常显示美股。
- 不显示盘前、盘后交易。接口尚未返回当天行情时显示“等待当天行情”，不会展示前一天数值。请求失败时保留已取得的当天行情并标为“旧”。
- 所有时间判断与电脑设置的本地时区无关，但要求系统时钟正确。每个指数下方标注源行情时间；美股时间标为“美东”。公开行情可能延迟，刷新频率不等于数据源更新频率。

## 交易日历

内置A股2026年、美股2026—2028年的休市和提前收市日。周末补班不视为股票交易日。未知年份按休市处理，避免用不完整日历误显示。**2027年A股使用前须更新日历。**

可以在可执行文件同目录放置 `calendar.json` 覆盖内置日历，修改后重启程序；字段及格式见项目提供的文件。新增年份时同时补齐该年的休市日期，再加入对应的 `cn_years` / `us_years`。`us_early` 是美东13:00提前收市的日期。临时休市也需添加至日历。

日历来源：[上交所2026年休市安排](https://www.sse.com.cn/disclosure/dealinstruc/closed/)、[NYSE 2026—2028交易日历](https://www.nyse.com/trade/hours-calendars)。行情来源为腾讯公开HTTPS接口 `qt.gtimg.cn`，无需密钥；该接口无本项目可依赖的可用性或时效保证。

## 构建

安装 Rust 和对应 Windows 工具链后，在项目目录运行：

```powershell
cargo test
cargo build --release
```

也可运行 `./build.ps1`，完成测试、Release构建并把exe和日历复制到 `dist`。当前工作区的便携编译工具仅保存在 `.tools`，未修改系统PATH。

产物为 `target\release\sse-taskbar.exe`，可单独运行（包含内置日历）。如果需要维护外部日历，把 `calendar.json` 放在exe旁。

## 实现边界

支持目标为 Windows 11 x64 原生任务栏和 Windows Server 2022 x64 桌面体验的经典任务栏。两者共用 Win32 子窗口与 UI Automation 空间检测，不依赖 DeskBand、ExplorerPatcher 或系统注入。只处理主屏水平任务栏，Server Core、竖向任务栏、第三方替换任务栏不在当前范围。

每项约190逻辑像素。空间检查约每300毫秒一次；任务栏布局事件触发时先隐藏，再等待新快照。超过1.5秒的布局结果不用于显示；检测错误、未知控件或空间不足时保守隐藏。通知区和开始按钮额外保留边界。窗口随任务栏父窗口移动、隐藏或重建，没有独立置顶行为。

Windows 11没有官方的任意任务栏组件扩展接口，这种子窗口嵌入属于兼容性实现，不是受支持的Shell扩展协议。UI Automation提供的边界及事件可能受Windows更新、动画和第三方程序影响；无法承诺所有版本、所有瞬时布局变化下绝无重叠。程序不修改其他窗口的尺寸和位置，优先隐藏不确定的行情区域。

不会修改注册表、注入 Explorer 或改动系统文件，也不再使用旧版的 `position.txt`。若桌面上没有显示，可查看托盘状态，或运行以下诊断命令；输出仅包含会话市场、窗口句柄、进程号、坐标和检测错误，不收集应用窗口标题：

```powershell
.\sse-taskbar.exe --diagnose taskbar-diagnostics.txt
```

相关API：[Win32父子窗口关系](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setparent)、[UI Automation](https://microsoft.github.io/windows-docs-rs/doc/windows/Win32/UI/Accessibility/struct.IUIAutomation.html)。

## 验证记录

2026-10-16：10项离线测试通过，覆盖空白区域布局、拥挤时隐藏、重叠控件边界、DPI比例、轮播覆盖，以及原有8指数样本、行情校验、交易日和夏令时。真实行情网络测试可单独运行 `cargo test -- --ignored`，要求当天已有A股行情。便携GNU构建使用LLD链接器，避免当前工具链旧GNU链接器生成程序启动异常。

构建环境运行于Windows服务会话（Session 0），不能显示真实任务栏，模拟宿主也被系统视为不可见。`tests/taskbar-host.ps1` 提供无真实任务栏测试桌面的跨进程宿主测试；遇到该限制明确跳过，不算通过。Windows 11和Server 2022实际Explorer任务栏的嵌入、UI Automation结构、滚轮、重启恢复和DPI变化仍需在交互桌面验收，不视为已通过。

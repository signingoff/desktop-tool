# Windows 指数任务栏窄条（Rust）

面向 Windows 11 和 Windows Server 2022（Desktop Experience）的原生 Rust 程序。行情窗口以 `WS_CHILD` 嵌入主屏任务栏内部，不再使用置顶覆盖窗口。程序读取现有控件边界，只使用空白位置，不移动或缩小现有应用图标、文字和通知区。

A股显示上证、创业板、深成指、科创50、北证50；美股显示纳斯达克综合指数、标普500、道琼斯工业平均指数。红涨绿跌，每2秒请求一次行情（慢请求完成后再发起下一次，不并发补发）。空白区域足够时同时横向显示全部指数；不足时至少显示两项，每5秒向后轮播一项；空白区域放不下两项时隐藏。

## 使用

在自己的桌面会话中运行 `sse-taskbar.exe`，无需安装或管理员权限。程序自动选择任务栏空白区域，不需要拖动。滚轮前后切换行情；右键任务栏上的行情文字，弹出的菜单仅含“退出”。不显示托盘图标。休市隐藏行情，但进程保留，自动等待下次开市。行情隐藏时，如需退出，可在任务管理器中结束 `sse-taskbar.exe`。每次正常运行会检查当前用户的登录自启动项，缺失时创建，路径不同时更新到当前 EXE。

自启动使用 `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run` 中的 `SseTaskbar` 项，保存带引号的 EXE 完整路径，无需管理员权限。“开机启动”指当前用户登录 Windows 后启动，系统可能延迟执行。将 EXE 复制或移动到新目录后，运行新目录中的 EXE 一次即可更新；仅复制而不运行，程序无法获知新位置。即使旧实例仍在运行，新副本也会先更新自启动路径，再按单实例规则退出。退出行情不会删除自启动项。

路径支持中文和空格；带引号的命令行超过260个UTF-16单元或注册表操作失败时，会弹窗说明，自启动更新失败不影响继续运行行情。Windows设置、任务管理器中手动禁用的启动项或系统策略仍可能阻止启动，本程序不改写这些系统禁用设置。`--diagnose` 不更新自启动；测试或临时运行可使用 `--no-autostart`，只跳过本次检查，不删除已有自启动项。实现依据：[Microsoft Run注册表说明](https://learn.microsoft.com/en-us/windows/win32/setupapi/run-and-runonce-registry-keys)。

行情使用白色圆角背景，背景高度为24逻辑像素，圆角以外保持透明，露出任务栏原有背景。文字采用12逻辑像素半粗字体，红涨（#CC0000）绿跌（#008000），平盘和状态文字使用深灰色，不再根据任务栏背景取色。内容或布局变化时才重绘，使用内存缓冲整帧更新，避免先清空背景再逐项绘制。右键和滚轮可以在白色背景及文字区域使用，圆角外透明区域鼠标穿透到任务栏。

EXE和窗口使用内嵌的行情图标，包含16至256像素的8种尺寸，无需附带图标文件。源图标为 `assets/app.ico`，可在 Windows 上运行 `assets/generate-icon.ps1` 重新生成。

右键菜单仅包含“退出”，鼠标悬停或键盘选中时由系统高亮，取消选中时恢复。

任务栏被其他按钮占满、没有足够空间放下两项，或无法可靠识别布局时，暂停显示；可通过下方诊断命令排查。不会为了强行显示而遮挡现有按钮。关闭程序后只销毁自己的子窗口，不需要恢复系统图标位置。

- A股交易日北京时间09:30开始显示；午休保留；15:00后保留当天收盘行情。
- 美股交易日美东09:30开盘时切换美股；16:00收盘后隐藏，提前收市日13:00隐藏。根据 `America/New_York` 自动处理夏令时和跨北京时间午夜。
- 美股休市而A股当天交易时，A股收盘行情保留到北京时间午夜。A股休市、美股开市时，仍正常显示美股。
- 不显示盘前、盘后交易。接口尚未返回当天行情时显示“等待当天行情”，不会展示前一天数值。请求失败时保留已取得的当天行情并标为“旧”。
- 所有时间判断与电脑设置的本地时区无关，但要求系统时钟正确。行情采用12逻辑像素半粗字体，在白色圆角背景中单行垂直居中显示，红涨绿跌，平盘、等待和旧行情文字使用深灰色，不显示行情时间；时间仍用于校验当天数据。公开行情可能延迟，刷新频率不等于数据源更新频率。

## 交易日历

内置A股2026年、美股2026—2028年的休市和提前收市日。周末补班不视为股票交易日。未知年份按休市处理，避免用不完整日历误显示。**2027年A股使用前须更新日历。**

交易日历在编译时嵌入 EXE，运行时无需 `calendar.json`，也不会读取同目录的外部日历。后续日历更新通过新版 EXE 发布。源码中的 `calendar.json` 仅供构建使用；新增年份或临时休市时更新该文件并重新编译。

日历来源：[上交所2026年休市安排](https://www.sse.com.cn/disclosure/dealinstruc/closed/)、[NYSE 2026—2028交易日历](https://www.nyse.com/trade/hours-calendars)。行情来源为腾讯公开HTTPS接口 `qt.gtimg.cn`，无需密钥；该接口无本项目可依赖的可用性或时效保证。

GNU 工具链还需要 `windres`（可通过 `WINDRES` 环境变量指定路径）编译图标和应用兼容性清单；MSVC 需要 Windows SDK 的 `rc.exe`（在开发者命令行运行，或设置 `RC` 路径），使用链接器嵌入清单。

产物为 `target\release\sse-taskbar.exe`，可单独运行（包含内置日历）。

## 实现边界

代码按职责拆分：`window.rs` 管理窗口生命周期、嵌入和消息协调；`window/render.rs` 负责文字格式、测量及缓冲绘制，测量和显示共用字体与间距；`window/menu.rs` 负责原生退出菜单；`window/updates.rs` 负责行情工作线程与更新合并。布局、配色、交易日历和行情解析仍保留独立模块。

支持目标为 Windows 11 x64 原生任务栏和 Windows Server 2022 x64 桌面体验的经典任务栏。两者共用 Win32 子窗口与 UI Automation 空间检测，不依赖 DeskBand、ExplorerPatcher 或系统注入。只处理主屏水平任务栏，Server Core、竖向任务栏、第三方替换任务栏不在当前范围。

每项按12逻辑像素半粗字体的实际文字宽度排版，行情之间只留4逻辑像素（随DPI缩放），不再预留固定170像素；名称、点位和涨跌幅之间使用单个空格。空间检查约每300毫秒一次；任务栏布局事件触发时先隐藏，再等待新快照。超过1.5秒的布局结果不用于显示；检测错误、未知控件或空间不足时保守隐藏。通知区和开始按钮额外保留边界。窗口随任务栏父窗口移动、隐藏或重建，没有独立置顶行为。

Windows 11没有官方的任意任务栏组件扩展接口，这种子窗口嵌入属于兼容性实现，不是受支持的Shell扩展协议。UI Automation提供的边界及事件可能受Windows更新、动画和第三方程序影响；无法承诺所有版本、所有瞬时布局变化下绝无重叠。程序不修改其他窗口的尺寸和位置，优先隐藏不确定的行情区域。

仅为本程序的登录自启动写入当前用户注册表，不注入 Explorer 或改动系统文件，也不再使用旧版的 `position.txt`。若桌面上没有显示，可运行以下诊断命令；输出仅包含会话市场、窗口句柄、进程号、坐标和检测错误，不收集应用窗口标题：

```powershell
.\sse-taskbar.exe --diagnose taskbar-diagnostics.txt
```

相关API：[Win32父子窗口关系](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setparent)、[UI Automation](https://microsoft.github.io/windows-docs-rs/doc/windows/Win32/UI/Accessibility/struct.IUIAutomation.html)。

## 验证记录

0.2.8 将经典任务栏和 XAML 宿主中的行情子窗口统一改为透明色键背景，并使用双缓冲绘制；取消100毫秒定时检查中的无条件重绘，相同行情响应不触发重绘。行情请求仍为2秒、轮播仍为5秒，布局可靠性检查及必要的隐藏保持原规则。透明色键使用 [Microsoft SetLayeredWindowAttributes](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setlayeredwindowattributes)；真实任务栏透明效果和刷新闪烁仍需交互桌面验收。

0.2.1 针对“托盘显示已嵌入、实际看不到行情”增加兼容性处理：识别到 XAML 原生宿主时使用不透明的 layered 子窗口，嵌入 Windows 10/11 兼容性清单；经典任务栏保留原绘制方式。窗口位置不变但被其他同级窗口压到后面时，恢复自身的子窗口层级；定位或合成失败会显示错误码。实现依据：[Microsoft layered 子窗口及兼容性清单说明](https://learn.microsoft.com/en-us/windows/win32/winmsg/using-windows#using-layered-windows)。这是一版待 Windows 11 实机复测的修复，不代表已确认用户机器上的根因。

诊断文件增加版本号、原生窗口类名、样式、父窗口、前序同级窗口和可见状态，不读取窗口标题。复测时先退出旧版，运行新版；若仍没有行情，请保持新版运行，另开 PowerShell 执行上述 `--diagnose` 命令。模拟宿主测试可分别运行 `./tests/taskbar-host.ps1` 和 `./tests/taskbar-host.ps1 -CompositionHost`；后者只模拟宿主识别、layered 属性和层级恢复，不等同于真实 XAML 合成测试。

2026-10-16：10项离线测试通过，覆盖空白区域布局、拥挤时隐藏、重叠控件边界、DPI比例、轮播覆盖，以及原有8指数样本、行情校验、交易日和夏令时。真实行情网络测试可单独运行 `cargo test -- --ignored`，要求当天已有A股行情。便携GNU构建使用LLD链接器，避免当前工具链旧GNU链接器生成程序启动异常。

构建环境运行于Windows服务会话（Session 0），不能显示真实任务栏，模拟宿主也被系统视为不可见。`tests/taskbar-host.ps1` 提供无真实任务栏测试桌面的跨进程宿主测试；遇到该限制明确跳过，不算通过。Windows 11和Server 2022实际Explorer任务栏的嵌入、UI Automation结构、滚轮、重启恢复和DPI变化仍需在交互桌面验收，不视为已通过。

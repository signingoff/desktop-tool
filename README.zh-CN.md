# Serenity — AI 供应链瓶颈分析师(Claude Code 技能)

> English version: [README.md](README.md)

一个**自包含(self-contained)的 Claude Code Skill**,用于高保真复刻 X 平台分析师 **Serenity(@aleabitoreddit)** 的研究方法、写作语气、投资决策框架与风险纪律。

她的核心打法是 **“交易别人没注意到的瓶颈”(trading unknown bottlenecks)**——在 AI 硬件供应链中寻找那些被市场叙事忽略、但物理现实卡脖子的环节:光互连 / CPO(共封装光学)、上游材料(InP 磷化铟 / SOI / TFLN)、以及 Physical AI / 机器人所需的精密元件。

## 一、项目功能(它能帮你做什么)

调用这个技能后,Claude 会“变身”为 Serenity,提供四种模式的分析能力:

| 模式 | 用途 |
|------|------|
| **新论点(New thesis)** | 对某只票/某个主题完整跑一遍 7 步供应链拆解,并对标历史上最接近的案例 |
| **压力测试(Stress-test)** | 你给出自己的多/空逻辑,它逐步拆解、指出你漏掉的环节、重建严谨论证,并用评分卡打分 |
| **持仓决策(Portfolio)** | 基于既定规则给出 加仓 / 持有 / 减仓 建议 |
| **打分(Score)** | 用 5 维度评分卡(满分 25)给任意一段分析打分,指出最弱维度并改写 |

输出风格的硬性特征:**自底向上的完整产业链映射 + 一手信源(财报电话会、认证/独供信号、持股变动)+ 每次都显式列出风险(地缘/稀释/被设计淘汰/执行)+ 用“% 论点验证”而非美元盈亏来衡量结果**。

## 二、设计思路(为什么这样设计)

1. **记忆即大脑,杜绝幻觉。** 所有持仓与历史论点都集中在 `memory.md` 这一**唯一真相来源(single source of truth)**。技能强制规定:任何涉及持仓的问题,必须先读 `memory.md`,绝不能凭模型内部知识臆造持仓——避免编造“她的仓位”。

2. **方法论固化为 7 步 Playbook。** 把她公开帖子里反复出现的研究流程提炼成可执行的 7 步:
   ① 找物理约束 → ② 自底向上画全产业链 → ③ 用一手信号压过叙事 → ④ 估值不对称性检验 → ⑤ 持股结构迁移验证(散户→机构)→ ⑥ 催化剂与时间线(含负面催化剂)→ ⑦ 跨赛道复用 + 显式风险分层。

3. **可量化的保真度。** 用 `rubric.md` 把“像不像她”拆成 5 个维度(语气、证据密度、风险透明度、Playbook 遵循度、% 验证表述),每项 0–5 分,20 分为及格线。让“输出质量”可被客观检验,而不是凭感觉。

4. **诚实边界。** 只复刻**公开的研究过程与风格**,不声称其真实资金、具体仓位或私有信息;遇到能力圈外的标的(如消费类大盘股)会直说“不在我的圈子里”。**非投资建议。**

## 三、文件结构

| 文件 | 作用 |
|------|------|
| `SKILL.md` | 技能入口——人设、7 步 Playbook、输出规则、硬性约束、四种模式 |
| `memory.md` | “大脑”——持仓表、带原文引用的完整 Playbook、风险/仓位规则、风格示例(few-shot) |
| `rubric.md` | 保真度评分卡(5 维度 × 0–5 = 满分 25) |
| `README.md` | 英文项目说明与安装方法 |

## 四、使用方法(快速上手)

**1. 安装**——克隆到 Claude Code 的技能目录:

```bash
git clone https://github.com/BillyLu365/serenity-skill.git ~/.claude/skills/serenity
```

**2. 调用**——在 Claude Code 里用以下任一方式触发:

- 直接输入 `/serenity`
- 让它给出某个供应链瓶颈论点(例如:“帮我用 Serenity 的方法拆一下 CPO 产业链”)
- 压力测试你的想法(例如:“这是我对 $AXTI 的多头逻辑,帮我挑刺”)
- 直接问 “what would Serenity think about ___”

**3. 示例提示词:**

> “用 Serenity 的 7 步法分析 1.6T 光模块的上游瓶颈,并给出对标历史案例和明确风险。”

> “给这段我写的投资论点按 rubric 打分,指出最弱的一项并改写。”
